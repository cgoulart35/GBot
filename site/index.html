Your server's own AI agent

Tell it how to behave in plain words. Make it a helper in one channel and a comedian in another, and decide when it replies and who it listens to.

GBot APP

Glad you asked! The next storm could hit any time. Keep your umbrella handy with /storms umbrella. 🌧️

The agent uses Claude, with your own API key from the Claude Console, so you stay in control of what it costs. Messages in channels where it's on are sent to Anthropic so it can respond, and it stays off until an admin turns it on.

Up and running in three steps

  1. Subscribe

    Join the GBot tier on Patreon with your Discord account linked. You'll be invited to the GBot Patreon server.

  2. Register your server

    In the Patreon server, run /patreon with your server's ID to enable GBot there.

  3. Turn on the fun

    Most features start off. Admins pick what they want with /config toggle, and everyone can see what's available with /help.

GBot only stays in subscribed servers. If it leaves a server, that server's GBot settings are lost, while GCoin balances stay with each user.
